# Theme Directory

This directory contains the Design System and styling tokens for Felinode.

## Usage
Import values from here instead of hardcoding colors or sizes.

- **`colors.ts`**: Palette definitions (Primitives and Semantic colors).
- **`typography.ts`**: Font families, sizes, and line heights.
- **`spacing.ts`**: Margins and paddings (e.g., xs, sm, md, lg, xl).
- **`theme.ts`**: The main theme object combining all tokens.

## Goal
To maintain a "Premium" aesthetic with consistent gradients and visual harmony.
